# Hireuno - Full Stack Job Portal

Hireuno is a full-stack job portal application built using React, Spring Boot, and MySQL. It allows users to search and apply for jobs while administrators can manage jobs and candidate applications.

## Features

### User
- Register and Login
- JWT Authentication
- Browse and Search Jobs
- Apply for Jobs
- Prevent Duplicate Applications
- Track Application Status
- User Profile

### Admin
- Admin Dashboard
- Post New Jobs
- Edit Jobs
- Delete Jobs
- View Candidate Applications
- Select or Reject Candidates

## Tech Stack

**Frontend:** React, JavaScript, HTML, CSS, React Router

**Backend:** Java, Spring Boot, Spring Data JPA, REST API

**Database:** MySQL

**Security:** JWT Authentication, BCrypt Password Hashing

**Tools:** Git, GitHub, Maven, VS Code

## How It Works

1. User creates an account and logs in.
2. User searches available jobs.
3. User applies for a job.
4. Application is stored in MySQL.
5. Admin views candidate applications.
6. Admin selects or rejects candidates.
7. User can track the application status.
